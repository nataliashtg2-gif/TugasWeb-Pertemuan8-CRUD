# Tugas Web Pertemuan 8 - CRUD Inventaris

Aplikasi CRUD Inventaris Barang berbasis PHP dan MySQL untuk Tugas Rutin Pertemuan 8. Dilengkapi dashboard, CRUD produk, pencarian, filter, pagination, JOIN database, validasi, activity log, export CSV, dan cetak laporan.

## Teknologi
- PHP 8+
- MySQL / MariaDB
- PDO
- HTML, CSS
- XAMPP

## Database
Database: `inventaris_db`

Import `schema.sql` melalui phpMyAdmin sebelum menjalankan aplikasi.

## Menjalankan
1. Salin folder project ke `C:\xampp\htdocs\TugasWeb-Pertemuan8-CRUD`.
2. Jalankan Apache dan MySQL di XAMPP.
3. Import `schema.sql` ke MySQL/phpMyAdmin.
4. Buka `http://localhost/TugasWeb-Pertemuan8-CRUD/`.

## Fitur
- Dashboard dan statistik inventaris
- CRUD produk
- Dropdown kategori dan supplier
- JOIN kategori dan supplier
- Search dan filter
- Pagination
- Validasi dan prepared statements
- Flash message
- Activity log
- Transaction saat delete
- Export CSV
- Cetak laporan
- Responsive UI
